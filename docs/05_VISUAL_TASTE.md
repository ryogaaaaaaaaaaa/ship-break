# 05 VISUAL TASTE

現時点では詳細なアートバイブルを作らない。

## 原則

- 暗いソフトウェア/デバッグの空気を持つ。
- プレイヤーと敵は常に読み分けられる。
- 通常ゲーム状態は清潔で読みやすく見える。
- 壊れた状態は徐々に画面へ侵入してよい。
- 意図的なエラー表現は、何が起きているか読める必要がある。
- ありがちな hacker-green 一色を唯一の個性にしない。
- エフェクトは飾りではなく、メカニクスを伝える。

## 第1マイルストーンの仮ビジュアル

- プレイヤーは明るいシアンの円。
- Chaser は赤系の円。
- 弾は明るい黄系の小円。
- 壁と境界は低彩度の矩形。
- ヒット、死亡、ダッシュは小さな色変化で表現する。

最終アートではない。読みやすさと検証のための仮表示である。
