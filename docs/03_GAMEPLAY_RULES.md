# 03 GAMEPLAY RULES

## 現在の通常ゲーム

第1マイルストーンでは、60秒の通常ゲームだけを作る。

プレイヤー:

- 移動できる。
- マウス方向へ照準する。
- 通常弾を撃てる。
- 短距離ダッシュできる。
- 体力が0になると死亡する。

Chaser:

- スポーン地点から出現する。
- プレイヤーへ直進する。
- プレイヤーへ近づくほど短く加速し、放置すると圧が高まる。
- 接触でプレイヤーにダメージを与える。
- 弾でダメージを受け、体力0で消える。

ラン:

- 60秒生存で成功。
- プレイヤー死亡で失敗。
- `R`、終了画面のタップ、クリック、`Enter`、`Space` で新しいランとしてリスタート。
- 時間経過で敵スポーン間隔が短くなる。
- 終盤10秒に `BUILD INSTABILITY` の予兆が出る。
- 予兆は見た目だけで、まだバグ選択やルール変更は発生しない。
- 60秒生存成功時は `BUILD INTERRUPTED` のデバッグ割り込み画面を表示する。
- 割り込み画面上の `FIX` / `WORKAROUND` / `EXPLOIT` は未接続表示であり、まだ選択肢としては機能しない。

フィードバック:

- 射撃時に短い発射音と銃口フラッシュが出る。
- 命中時に短いヒット音とスパークが出る。
- 敵撃破時に低い撃破音とリングが出る。
- ダッシュ時に短い上昇音と軌跡が出る。
- 被弾時に重い音と赤いリングが出る。
- Chaser が近いほど画面端の危険表示が強くなり、接近圧を伝える。
- スマホの右側ドラッグ中は照準線が伸び、射撃方向を読みやすくする。
- 成功時は通常の勝利文だけで終わらず、ゲームがデバッグ画面へ割り込まれたように見せる。
- これらは仮演出であり、最終サウンド/アートではない。

## MVP バグカタログ

この節は仕様であり、第1マイルストーンでは実装しない。

### COLLISION FAILURE

- `FIX`: 通常の衝突へ戻す。
- `WORKAROUND`: 合法エリア外へ出た敵を削除する。報酬はない。
- `EXPLOIT`: プレイヤーと敵が選択された壁を通り抜けられる。

### INPUT BUFFER OVERFLOW

- `FIX`: 入力を即時実行へ戻す。
- `WORKAROUND`: プレイヤー行動が短く遅延し、順番に放出される。
- `EXPLOIT`: 対象行動が二重実行される。敵側の一部挙動も複製され得るが、明示上限が必要。

### DUPLICATE REFERENCE

- `FIX`: 重複オブジェクト挙動を取り除く。
- `WORKAROUND`: 一部敵が低体力の複製を作る。複製は報酬を出さない。
- `EXPLOIT`: 対象敵と対象弾が複製される。指数的増殖は禁止。

### MEMORY LEAK

- `FIX`: 倒された敵を素早く片付ける。報酬も早く消える場合がある。
- `WORKAROUND`: 死体が一時的に残り、物理障害物になる。
- `EXPLOIT`: 死体を攻撃して爆発させられる。各死体は原則1回だけ爆発する。

### TIME DESYNC

- `FIX`: 通常時間へ戻す。
- `WORKAROUND`: 一定間隔で全体が短くスローになる。
- `EXPLOIT`: 世界はスロー、プレイヤーは通常速度、後で敵に補償加速が入る。

### UI LEAK

- `FIX`: UI システムがリセットされ、重要情報が一時的に消える場合がある。
- `WORKAROUND`: エラーウィンドウがアリーナ内の物理オブジェクトになる。
- `EXPLOIT`: プレイヤーがエラーウィンドウを操作し、敵を遮る、押す、制御された条件で潰す。

## TEST RUNNER

将来の最終ボス。プレイヤーが選んだバグに応じて、事前定義された boss echo を使う。
動的に攻撃を発明しない。データ駆動かつ bounded にする。
