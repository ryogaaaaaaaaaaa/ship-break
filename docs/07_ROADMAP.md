# 07 ROADMAP

## 完了: 第1マイルストーン土台

- 最小 Godot プロジェクト。
- ルール/RNG 基盤。
- 初期テスト。
- 60秒通常ゲーム。
- スマホ向けの最低限タッチ操作。
- GitHub Pages 用 Web 書き出し。

## 完了: 通常ゲームの個性づけ

- 敵数を抑え、Chaser 1体ごとの圧を上げた。
- 射撃を少し遅く、速い弾で狙う感触に寄せた。
- 障害物を射線と誘導に使いやすい配置へ調整した。
- 終盤10秒に `BUILD INSTABILITY` の見た目予兆を追加した。
- 射撃、命中、撃破、ダッシュ、被弾に最小限の音と視覚フィードバックを追加した。
- Chaser 接近時の危険表示と、右側ドラッグ射撃の照準表示を強化した。

## 完了: 次章への入口

- 60秒生存成功時に `BUILD INTERRUPTED` のデバッグ割り込み画面を表示するようにした。
- 終了画面からタップ、クリック、`Enter`、`Space`、`R` で再起動できるようにした。
- `FIX` / `WORKAROUND` / `EXPLOIT` は未接続表示に留め、まだ本物のバグ選択 UI にはしていない。

## 次に推奨する1ステップ

最初の小さなバグイベントを1つだけ接続し、通常ゲームが「壊れ始める」瞬間を作る。

具体的には、次の1マイルストーンに絞る。

- `COLLISION FAILURE` か `TIME DESYNC` のどちらか1つを選ぶ。
- 選択肢は3つ全部ではなく、まず `WORKAROUND` 1本だけを実装する。
- 選択後に `RulePatch` が適用され、プレイヤーが変化を画面上で読める状態にする。
- 自動テストで、選択前後の `RuleSnapshot` とラン再開状態を確認する。

ボスにはまだ進まない。

## Web / Pages 確認

GitHub Pages 用の Web 書き出しは追加済み。
スマホ確認では、性能よりもまず次を確認する。

- 起動するか。
- 画面サイズに収まるか。
- 仮想スティックで移動できるか。
- 右側ドラッグで射撃できるか。
- 右下ボタンでダッシュできるか。
