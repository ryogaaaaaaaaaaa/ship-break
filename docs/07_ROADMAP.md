## 次に推奨する1ステップ

通常ゲームの手触りを改善しつつ、60秒ランの難易度と視認性をプレイテストする。

具体的には、次の1マイルストーンに絞る。

- Chaser の速度、スポーン間隔、プレイヤー弾速、ダッシュ距離を調整する。
- 手動プレイテストで「普通のゲームとして読めるか」を確認する。
- 数値は `RuleState` の初期値として調整する。

バグ選択 UI やボスにはまだ進まない。

## Web / Pages 確認

GitHub Pages 用の Web 書き出しは追加済み。
スマホ確認では、性能よりもまず次を確認する。

- 起動するか。
- 画面サイズに収まるか。
- 仮想スティックで移動できるか。
- 右側ドラッグで射撃できるか。
- 右下ボタンでダッシュできるか。
