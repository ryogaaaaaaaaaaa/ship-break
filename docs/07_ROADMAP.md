# 07 ROADMAP

## 完了: 第1マイルストーン土台

- 最小 Godot プロジェクト。
- ルール/RNG 基盤。
- 初期テスト。
- 60秒通常ゲーム。
- スマホ向けの最低限タッチ操作。
- GitHub Pages 用 Web 書き出し。

## 完了: 通常ゲームの個性づけ

- 敵数を抑え、Chaser 1体ごとの圧を上げた。
- 射撃を少し遅く、速い弾で狙う感触に寄せた。
- 障害物を射線と誘導に使いやすい配置へ調整した。
- 終盤10秒に `BUILD INSTABILITY` の見た目予兆を追加した。
- 射撃、命中、撃破、ダッシュ、被弾に最小限の音と視覚フィードバックを追加した。
- Chaser 接近時の危険表示と、右側ドラッグ射撃の照準表示を強化した。

## 完了: 次章への入口

- 60秒生存成功時に `BUILD INTERRUPTED` のデバッグ割り込み画面を表示するようにした。
- 終了画面からタップ、クリック、`Enter`、`Space`、`R` で再起動できるようにした。
- `FIX` / `WORKAROUND` / `EXPLOIT` は未接続表示に留め、まだ本物のバグ選択 UI にはしていない。

## 完了: 最初のバグ変化

- `TIME DESYNC WORKAROUND` を1本だけ接続した。
- 初回60秒成功後、`WORKAROUND` 選択で `RulePatch` が入り、次のランから一定間隔の短いスローが発生する。
- スロー中はプレイヤー、敵、弾、スポーン、ラン時間が同じ係数で遅くなる。
- 画面の青い乱れ、`TIME DESYNC` 表示、専用音で発生タイミングを読めるようにした。

## 完了: 最小選択UI

- 成功画面に `FIX` / `WORKAROUND` / `EXPLOIT` の3枠を置いた。
- 最初は `WORKAROUND` だけ選択可能にし、`FIX` と `EXPLOIT` はロック表示にした。
- 成功画面の背景タップだけでは適用しないようにした。

## 完了: TIME DESYNC 3択化

- `FIX` / `WORKAROUND` / `EXPLOIT` の3択をすべて選択可能にした。
- `FIX` は次ランの `TIME DESYNC` を解除する。
- `WORKAROUND` は世界全体の短いスローを継続する。
- `EXPLOIT` は世界側だけを短くスローにし、プレイヤーは通常速度で動けるようにした。
- 成功画面の `R` ショートカット適用は廃止し、明示的な選択枠だけで処置を決めるようにした。

## 次に推奨する1ステップ

次のバグファミリーを1つだけ追加する。

具体的には、次の1マイルストーンに絞る。

- `COLLISION FAILURE` か `MEMORY LEAK` のどちらかを選ぶ。
- まず1ファミリーだけ、3択をデータとテスト込みで追加する。
- 既存の `TIME DESYNC` と同時に複数パッチを保持するか、最新選択だけにするかを決める。

ボスにはまだ進まない。

## Web / Pages 確認

GitHub Pages 用の Web 書き出しは追加済み。
スマホ確認では、性能よりもまず次を確認する。

- 起動するか。
- 画面サイズに収まるか。
- 仮想スティックで移動できるか。
- 右側ドラッグで射撃できるか。
- 右下ボタンでダッシュできるか。
- 初回60秒成功後、次ランで `TIME DESYNC` の短いスローが発生するか。
