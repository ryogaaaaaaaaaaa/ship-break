# 07 ROADMAP

## 完了: 第1マイルストーン土台

- 最小 Godot プロジェクト。
- ルール/RNG 基盤。
- 初期テスト。
- 60秒通常ゲーム。
- スマホ向けの最低限タッチ操作。
- GitHub Pages 用 Web 書き出し。

## 完了: 通常ゲームの個性づけ

- 敵数を抑え、Chaser 1体ごとの圧を上げた。
- 射撃を少し遅く、速い弾で狙う感触に寄せた。
- 障害物を射線と誘導に使いやすい配置へ調整した。
- 終盤10秒に `BUILD INSTABILITY` の見た目予兆を追加した。
- 射撃、命中、撃破、ダッシュ、被弾に最小限の音と視覚フィードバックを追加した。
- Chaser 接近時の危険表示と、右側ドラッグ射撃の照準表示を強化した。

## 次に推奨する1ステップ

通常ゲームの手触りをスマホ実機で確認し、タッチ操作と難易度を調整する。

具体的には、次の1マイルストーンに絞る。

- 仮想スティックの位置とサイズを調整する。
- 右側ドラッグ射撃の狙いやすさを確認する。
- Chaser の加速距離、スポーン間隔、プレイヤー弾速、ダッシュ距離を調整する。
- 手動プレイテストで「普通のゲームとして読めるか」「ヴァンサバに寄りすぎていないか」を確認する。
- 数値は `RuleState` の初期値として調整する。

バグ選択 UI やボスにはまだ進まない。

## Web / Pages 確認

GitHub Pages 用の Web 書き出しは追加済み。
スマホ確認では、性能よりもまず次を確認する。

- 起動するか。
- 画面サイズに収まるか。
- 仮想スティックで移動できるか。
- 右側ドラッグで射撃できるか。
- 右下ボタンでダッシュできるか。
