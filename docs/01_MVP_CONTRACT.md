# 01 MVP CONTRACT

## MVP の問い

1回の10から12分のラン後、プレイヤーが「別のバグ組み合わせを試すためにもう一度始めたい」と思うか。

## MVP 固定スコープ

- プレイアブルキャラクターは1人だけ。
- アクションは移動、照準、通常攻撃、ダッシュ。
- メイン戦闘アリーナは1つ。
- 通常敵は最終的に Chaser、Shooter、Charger の3種類。
- 最終ボスは `TEST RUNNER` 1体。
- バグファミリーは最終的に6種類、各 `FIX` / `WORKAROUND` / `EXPLOIT` の18変種。

## 第1マイルストーン

現在の第1マイルストーンは、将来バグで壊すための通常ゲーム基盤を作ること。

含めるもの:

- 有効な最小 Godot プロジェクト。
- 日本語ドキュメント。
- `SeededRng`。
- 初期ルールシステム。
- 初期テスト。
- `tools/verify.ps1`。
- 60秒の通常ゲーム。
- プレイヤー移動、照準、射撃、ダッシュ、体力。
- Chaser 1種類。
- 簡単なアリーナ。
- 死亡、成功、リスタート。

含めないもの:

- バグ選択 UI。
- `FIX` / `WORKAROUND` / `EXPLOIT` の実装。
- 6種類のバグファミリー本実装。
- `TEST RUNNER`。
- Shooter と Charger。
- ショップ。
- 永続進行。
- セーブデータ。
- Steam 連携。
- 最終アート。

## 受け入れ条件

- プロジェクトが起動またはヘッドレス検証できる。
- `SeededRng` が存在し、同じ seed で同じ結果を返す。
- `RuleState`、`RulePatch`、`RuleResolver`、`RuleSnapshot` が存在し、テストされている。
- ゲームプレイ側が `RuleSnapshot` を読める。
- プレイヤーが移動、照準、射撃、ダッシュできる。
- Chaser が出現し、プレイヤーへ接近する。
- 敵がプレイヤーにダメージを与える。
- プレイヤーが敵を倒せる。
- プレイヤーが死亡できる。
- 60秒生存で成功状態になる。
- `R` でリスタートできる。
- リスタートで古い敵や弾が残らない。
- 検証コマンドが成功する。
